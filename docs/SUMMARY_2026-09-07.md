本文件总结一次大版本更新：**比赛模式（每轮 15 手 · 按轮结算）**、**6 个人格出牌逻辑优化**、**情绪系统量化** 与 **AI 难度梯度实测**。所有数据均可通过仓库内 `tests/` 脚本复现（零依赖纯 Node）。

## 一、比赛模式（🏆 每轮 15 手 · 按轮结算输赢）

在选桌弹窗选择「🏆 比赛 · 每轮 15 手」进入。规则完全按锦标赛形式实现：

| 项目 | 规则 |
|------|------|
| 起始筹码 | 每人 2000（开局 100BB，10/20 起步） |
| 一轮手数 | 每轮固定 **15 手**，手满自动弹窗结算 |
| 盲注阶梯 | 第1轮 10/20 → 第2轮 15/30 → 第3轮 25/50 → 40/80 → 60/120 → 100/200 → 150/300 → 250/500 → 400/800 → 600/1200 |
| 补筹 | **不补筹**。筹码归零 = 淘汰，之后不再发牌/行动 |
| 名次积分 | 每轮按筹码排名：第1名 **+5**、第2名 **+3**、第3名 **+1**，其余 0；积分全程累计 |
| 轮末结算 | 弹窗展示本轮筹码榜：名次/头像/名字/筹码/本轮盈亏/本轮积分/累计总分，前 3 名高亮（🥇🥈🥉）、自己标注、淘汰置灰 |
| 轮间操作 | 「下一轮」→ 盲注升级继续；「结束比赛」→ 直接看最终排名 |
| 终局冠军 | 只剩 1 人（持有全部筹码）→ 该幸存者强制第 1 并显示 🏆，其余按累计积分（同分比筹码）排序 |
| 中途退出 | 无自然幸存者时按累计积分排名，第 1 名显示 🏆 |

顶栏在比赛模式显示「第 N 轮 · 盲注」徽标；练习模式（无限手）行为完全不变。

## 二、AI 出牌逻辑优化

对 6 个人格逐一做了针对性修复与校准，**目标是难度梯度真实成立、且每个风格不被磨平**：

### 2.1 修复清单

| 人格 | 问题 | 修复 |
|------|------|------|
| solver🔬 / boss👑 | 翻后跟注线过死（`evEdge > -0.02` 才跟），弱对子/听牌被跟注站割 | 新增**防御性跟注分支**：有对子且赔率 <0.34、两对且 <0.48(单挑)、三条+ 且 <0.58、有听牌且 <0.28 时跟注防守 |
| boss👑 | 玩家建模未建立时缺乏侵略性 | 无 playerModel 时 bluff 修正 fallback +0.04；翻前加注概率按对手松紧动态修正（`raiseProb + (frP-0.35)*1.2`，上限 0.95），对方松则收敛至 +0.02 |
| lag🦈 | **根因级 bug**：`!facingBet` 分支 `cbetFreq*(0.7+pressure)` ≈ 1.34，导致 flop/turn/river **三条街无条件 100% 开火**，纯空气往跟注站身上送钱 | **街感知翻后收敛**：flop 维持高频 c-bet；turn/river 只有 (medium 或有听牌 或 rel≥1.1) 才以较高概率下注，单挑且 `rnd()<bluffFreq*0.5` 可偷一枪，纯空气/多人池一律过牌。facingBet 的 3-bet/诈唬分支保留（人设核心） |
| fish🐟 / rock🐶 / tag💼 | 基线微调 | rock/tag 保持教科书紧凶与紧弱风格边界；fish 维持松弱跟注站设定 |

### 2.2 难度梯度实测（赛制零和：6 人桌、起始 2000、不补筹、首破出局或 40 手封顶）

**修复前（400 session）**：solver 102.9 > boss 80.7 > rock 72.4 > tag 23.9 > fish -110.8 > **lag -119.3（垫底，比鱼还差）**

**修复后（600 session，最终版）**：

| AI | session 均盈亏 | 净赢/百手 | BB/百手 | 夺冠率 |
|----|--------------|----------|---------|-------|
| rock🐶 | +567.0 | +1512.3 | **+75.6** | 16% |
| boss👑 | +391.0 | +1307.8 | **+65.4** | 22% |
| tag💼 | +314.6 | +937.6 | **+46.9** | 17% |
| solver🔬 | +225.9 | +761.0 | **+38.0** | 22% |
| lag🦈 | -303.8 | -1573.0 | **-78.6** | 19% |
| fish🐟 | -819.8 | -3633.1 | **-181.7** | 10% |

**结论**：
- 紧的教科书流（rock/tag）与读牌/BOSS 层稳定盈利；solver 与 boss 在多次跑动中位次互有波动（短 session 方差大，参考夺冠率更稳）。
- lag 根因修复后由「差 fish 65BB」反转为「**领先 fish ~103BB**」，夺冠率 19% 仍体现松凶"短局有爆发"的特性，**风格未被磨平**。

## 三、情绪系统量化（情绪到底影响什么）

### 3.1 机制

每个座位有 `mood`（-100 上头 ~ +100 得意），由输赢/被诈唬/被 bad beat 等事件驱动，更新幅度乘人格的 `moodVolatility`。决策时情绪被折算成两个方向因子（brain.js 105-106 行）：

```
moodTilt = mood<0 ? (-mood/100)*vol : 0   // 上头因子 0..1
moodConf = mood>0 ? ( mood/100)*vol : 0   // 得意因子 0..1
```

### 3.2 源码中的 5 个调制点（brain.js，均已核实行号）

| # | 调制点 | 公式 | 效果 | 行号 |
|---|--------|------|------|------|
| 1 | 翻前起手范围 | `needTop *= (1 + moodTilt*0.35)` | 上头越狠，起手越松（放宽 35%） | 162 |
| 2 | 反偷(resteal)频率 | `restealFreq * (1 + moodTilt*0.5)` | 上头时更爱 3-bet 反击 | 167 |
| 3 | 偷盲(steal)频率 | `stealFreq * (1 + moodConf*0.4)` | 得意时更爱偷盲 | 179 |
| 4 | 跟注阈值 | `callThreshold + moodTilt*0.35` | 上头时跟注门槛大幅放宽（更难弃牌） | 267 |
| 5 | 诈唬频率 | `bluffFreq + moodTilt*0.32 + moodConf*0.12` | 上头加诈唬、得意小幅加诈唬 | 269 |

> 上头(负面)的影响面明显更大：放大入池范围、反偷、跟注、诈唬 4 处；得意(正面)主要放大偷盲与诈唬 2 处，幅度也更小。

### 3.3 各人格的情绪敏感度（moodVolatility）

| 人格 | volatility | 解读 |
|------|-----------|------|
| fish🐟 | 0.95 | 极度情绪化：连输就彻底放飞 |
| lag🦈 | 0.75 | 高波动：上头后开火更凶（也是他的破绽） |
| tag💼 | 0.40 | 会受影响但能收敛 |
| rock🐶 | 0.20 | 接近免疫 |
| boss👑 | 0.12 | 几乎不受情绪干扰 |
| solver🔬 | 0.06 | 纯机器，情绪影响可忽略 |

### 3.4 实测数据（`tests/mood_probe.js`：钉死 mood 跑 120 手/档，排除记仇干扰）

**fish🐟（vol 0.95）**：mood -100（上头）时 VPIP 升至 **~104%**（每手必入），PFR 与加注/手同步飙升 —— 完全丧失弃牌能力，纯送筹码。

**lag🦈（vol 0.75）**：mood -100 时 VPIP 相对平静档 **+16.7pt**，翻后跟注率上升 —— 上头后入池更宽、跟得更凶。

**rock🐶（vol 0.20）**：mood -100 ~ +100 全档行为几乎不变（超紧人设压过情绪）—— 实测证明低 volatility 玩家确实"情绪免疫"。

复现：`node tests/mood_probe.js [lag|rock|fish] [手数]`（默认 120 手/档）

**一句话总结**：情绪系统真正惩罚的是高 volatility 人格（鱼、鲨鱼）—— 它们赢钱会膨胀、输钱会放飞，情绪波动本身就是可被玩家利用的破绽；而 rock/solver/boss 靠低 volatility 维持稳定输出。

## 5. 追加（当日）：短码推推乐（push/fold）+ 行动节奏分级

**问题**：石头老张等紧人格在比赛后期进入短码后仍按深码逻辑小额操作，一路弃到被盲注磨死（"总是弃牌特墨迹"）；且 AI 行动前思考延时固定 650~1450ms，弃牌这类无脑决策也照等 1 秒+。

**修改**：
| 文件 | 改动 |
|---|---|
| `js/ai/personalities.js` | 每人格新增 `pushBB`（后手 ≤ pushBB×BB 进入推推乐）：rock 16 / lag 18 / tag 12 / boss 12 / solver 10 / fish 6，并补字段注释 |
| `js/ai/brain.js` | 翻前新增「短码推推乐」块（位于常规范围计算之后、反偷/偷盲之前优先执行）：越短推得越宽（urgency 0..1 叠加放宽至 +24pp）；偷盲位直接全下收池；强牌（前 pushTop×0.75）面对下注反推全下；仅盲注位 ≤1BB 且底池赔率极好才小额补跟（bbFill）；其余一律弃。短码区不再出现小额加注/磨蹭跟注 |
| `js/ui.js` | 行动节奏分级：先算出决策再按动作定延时 —— 弃牌/过牌 ≈350-550ms，跟注/加注略想，全下最久，消除"弃牌也发呆" |
| `tests/pushfold_probe.js` | 新增验证探针（新增）：6 座全人格 + autoRebuy 深码对手，钉住 rock 总深度逐手统计翻前决策 |

**实测**（钉住 rock 深度，每档 700 手翻前决策）：
- 25BB 深码对照：fold 83% / allin 1% / 小额跟注 8% / 小额加注 6%
- 8BB：fold 80% / **allin 16%** / 小额跟注 2% / 小额加注 0%（短码的"加注"全部转为全下）
- 3BB：fold 76% / allin 13% / 小额跟注 8%（仅盲注位 1BB 内超赔率补码）
- 结论：短码动作收敛为教科书式「全下或弃牌」，不再小额磨蹭；深码仍是原来的石头老张。

**回归**：`node tests/sim.js` / `tests/match_sim.js` / `tests/qa_probe.js` 全 PASS。
